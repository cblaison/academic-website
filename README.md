# Christophe Blaison — academic website

Vite + React static site for Christophe Blaison (MCF–HDR, LPS / Université Paris Cité).

Presentation language inspired by [Spaceship](https://chuanqisun.github.io/spaceship/) (atmospheric dark UI, strong typography, sparse chrome) adapted for academia — not a product clone.

## Develop

```bash
npm install
npm run dev
```

## Preview / publish

```bash
npm run build
npm run preview
```

Content is sourced from vault notes and local CV; see Project store `docs/profile-from-vault.md`.
